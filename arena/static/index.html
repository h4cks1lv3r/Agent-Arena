LOCAL CONNECTIONS

Connect paper accounts and model providers

Set broker and model credentials in the server’s .env file or environment, then restart the server. Never paste those keys into this dashboard. Each agent needs its own clean, dedicated Alpaca paper account with no positions or open orders.

The default check reads broker account status and market data. It places no orders. Paid model calls require the choice below.

Model API usage can incur real charges in paper mode, including research cycles that do not trade. The displayed model costs are estimates deducted from net experiment equity. Your loss-halt setting decides whether these charges count toward the loss threshold. The monthly model budget always applies, including paid connection tests. Model keys: OPENAI_API_KEY and ANTHROPIC_API_KEY. Set an exact model ID and its current USD-per-million-token rates above. Fresh presets select named models; saved experiments are not upgraded automatically.

First paper run: Set mode to Alpaca paper, create the experiment, reconcile, then resume entries. Each agent starts with its share of your total pool even if its broker paper account starts with $100,000. Profit compounding changes the risk-cap basis only when enabled.

External stop: Run Stop_New_Entries.bat on a Windows host to persist a halt independently of the dashboard. If the app is unavailable, use the Alpaca paper account website to inspect and cancel orders. The local stop file does not cancel existing broker orders.
